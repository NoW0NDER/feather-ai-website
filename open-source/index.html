A personal assistant should grow with the person using it. We are preparing Athena for an open-source release: an everyday starting point, with room to inspect, change and build.

Open-source release in preparation

The source repository is still private. Apache License 2.0 is planned for the next source release. We will publish the repository and setup instructions here when they are ready; no public source download is available yet.

Two ways to run Athena

Available now, with enabled access

Hosted preview

Download the Mac preview and sign in with an enabled Athena account. Model use draws from your account credit. The web version runs in a separate Linux environment. Neither option requires you to bring a provider key.

In preparation for the source release

Local, with your own key

The planned local mode will run without an Athena account and use a provider key you configure yourself. Provider usage is billed by that provider. You will be responsible for configuration, updates and any extensions you enable. A remote model still receives the content needed for your requests.

What we want to make possible

01

A capable beginning.

An ordinary request should lead to something useful. Files, conversation and actions belong to one task, with progress that can be understood and checked.

02

Change that serves the work.

A different model, a focused work surface or an extension should help the task at hand. We are building toward replaceable parts of the harness; this is an architectural direction, not a claim that every part is replaceable today.

03

Room to recover.

Agent-authored extensions belong outside the application code. Stop and reset remain independent. Recovery should preserve the conversation and files, rather than ask you to begin again.

What to know today

The current Mac download is an early Apple Silicon test build for macOS 13 or later, without Apple notarization. Mac and web histories do not sync. Voice, browser and computer interactions still need careful setup and testing. Do not assume unattended actions will always succeed. Local BYOK is not part of the published release yet; Windows, iOS and Android packages are not available here.

A contribution starts with a real use

When the repository opens, we want reproducible problems, small reviewable changes and examples of real tasks. Describe what you expected, what happened and how to verify the result. Use synthetic fixtures; keep credentials, private conversations and personal files out of reports and patches.

Contribution instructions and the issue tracker will be linked here with the public repository. There is no separate community or plugin marketplace to join at this stage.

While we prepare the source release

The Mac preview is available through our download page. Its build details and signing status are the source of truth for what you can install today.

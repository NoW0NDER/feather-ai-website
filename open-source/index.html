Two ways to run Athena

Available now, with enabled access

Hosted preview

Download the Mac preview and sign in with an enabled Athena account. Model use draws from your account credit. The web version runs in a separate Linux environment. Neither option requires you to bring a provider key.

Available from source

Local, with your own key

Run the source locally without a Feather account. Connect your own Chat Completions API or a compatible model server already running on your computer. Remote provider use is billed by that provider; local models can use a loopback connection without a key. You manage setup, updates and extensions.

The local settings form supports Chat Completions, not native Anthropic Messages or Responses APIs. A remote model receives the content needed for each request. Local storage does not mean offline AI.

What we want to make possible

01

A capable beginning.

An ordinary request should lead to something useful. Files, conversation and actions belong to one task, with progress that can be understood and checked.

02

Change that serves the work.

A different model, a focused work surface or an extension should help the task at hand. We are building toward replaceable parts of the harness; this is an architectural direction, not a claim that every part is replaceable today.

03

Room to recover.

Agent-authored extensions belong outside the application code. Stop and reset remain independent. Recovery should preserve the conversation and files, rather than ask you to begin again.

What to know today

The downloadable DMG is a hosted Apple Silicon preview for macOS 13 or later, without Developer ID signing or Apple notarization. BYOK is available from source; there is no prebuilt BYOK installer here. Mac and web histories do not sync. Voice, browser and computer interactions need setup and validation; unattended actions can fail. Windows, iOS and Android packages are not available here.

A contribution starts with a real use

We welcome reproducible problems, small reviewable changes and examples of real tasks. Describe your goal, what happened and how to verify the result. Use synthetic fixtures; keep credentials, private conversations and personal files out of reports and patches.

Read the contribution guide before opening a pull request. There is no response-time guarantee, separate community or plugin marketplace at this stage.
